# Examples

Complete scripts to copy and adapt.

| Example | What it shows |
| --- | --- |
| [A session file](session-file.md) | Sign in once, save every renewed session, sign in again only when needed |
| [Real estate categories](real-estate.md) | Every postable real estate category with its params, printed as a reference |
| [Post from CSV](post-from-csv.md) | Flats from a spreadsheet, one row per ad, photos from folders |
| [Moderation watch](moderation-watch.md) | Follow new ads through moderation and send a Telegram message when one is rejected |
| [Django](django.md) | A model for ads, a management command and the session in the database |

The repository has a posting script too: [examples/post_flat.py](https://github.com/qiyascc/lalafo-python-sdk/blob/main/examples/post_flat.py).
