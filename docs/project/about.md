# About

lalafo Python SDK is a typed client for lalafo.az. It lets agencies, shops and developers post and manage ads from their own systems with the same steps and checks as the lalafo website. It is not affiliated with lalafo.

## Author

The SDK is written and maintained by **Qiyas Sadıqov**. More of his work, including the other libraries listed below, is on [theqiyas.cc](https://theqiyas.cc).

## Other libraries by the same author

They share the same shape: typed models, sync and async clients built on httpx, settings through goodconf, every message in a YAML file and retry rules that never repeat a write by accident. Once you know one, the others read the same way.
